# A11y 0.2.1

- Home and document tabs share the window title-bar row. macOS keeps its native window controls; Windows has minimize, maximize/restore and close controls on the right, plus drag and edge resizing.
- File in the left rail opens the document's layers. File commands remain in the main menu.
- The unused Tools entry is removed from the left rail.
- Copying a main component and pasting creates an instance linked to that main component. Cut/paste still moves a main component. Across files, paste imports a local main component on the hidden library page and creates an instance of it; it does not establish a live library link to the source file. Numeric node IDs from another file cannot accidentally bind to an unrelated component.
- The username dropdown offers Edit display name and Sign out. The current app uses local profiles and a shared workspace key rather than individual server accounts. Sign out forgets the saved shared connection key and catalog on this machine, ends its session, resets the displayed name to Guest, and keeps local documents. Reconnect with the workspace key to return to shared files. It does not revoke the shared key for other users or stop the server.

Existing A11y 0.2.0 installations can receive this release through Help → Check for updates, then Update now → Restart to update. The collaboration server does not need a change; wire protocol 3 is retained.

Validation: app regression tests, strict Clippy, macOS release build and Windows x64 cross-build. Native Windows window interactions still require a Windows-machine check. Two real-network tests remain excluded in the sandbox; the shared server is managed separately.
